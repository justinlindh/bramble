Device Setup

Give your node a name and connect it to WiFi. This lets you manage it wirelessly from the Bramble web app on your phone or computer.

🔒 Security (optional)

Set an auth token to require a password for wireless connections. Without a token, anyone on your network can connect to this device. You can always change this later with the CLI or web app.

Save this token — you'll need it to connect wirelessly via the web app or CLI.
